# РИСсити Кликер

Браузерная игра-кликер для гостей ресторана РИСсити. QR-код на столе → игра на телефоне → скидка на счёт.

**Только мобильные устройства.** Десктопная версия не проектируется.

## Требования

- Node.js 20.9 или новее. Разработка ведётся на Node 24 — встроенный модуль `node:sqlite` требует именно его.
- pnpm 10.

## Запуск

```bash
pnpm install
cp .env.example .env
mkdir -p data
pnpm db:migrate
pnpm dev
```

Без `pnpm db:migrate` таблиц не будет и API вернёт ошибку. Повторять после каждого изменения схемы.

Открывать с телефона в одной сети: `pnpm dev --hostname 0.0.0.0`, затем зайти на `http://<ip-компьютера>:3000`.

## Контроль качества

Git-хуки ставятся автоматически при `pnpm install`.

- **pre-commit** — Biome по изменённым файлам, проверка типов, затронутые юнит-тесты.
- **pre-push** — полный прогон тестов с покрытием, сборка, e2e.
- **commit-msg** — Conventional Commits.

Порог покрытия для `src/game` — 100% ветвей. Это чистые функции без зависимостей, отговорок нет.

## Деплой

Приложение разворачивается на собственном сервере владельца.

**Сервер и база данных обязаны физически находиться в РФ** — требование 242-ФЗ к хранению персональных данных россиян.

Обязательные переменные окружения — см. `.env.example`. Каталог из `DATABASE_PATH` должен существовать и быть доступен на запись.

```bash
pnpm install --frozen-lockfile
pnpm build
pnpm db:migrate
pnpm start
```

## Как устроена защита

Сервер авторитетен. Клиент присылает только количество тапов за окно синхронизации; зёрна, скидку и время считает сервер по своим часам. Сессия опознаётся по случайному идентификатору в httpOnly-куке, состояние хранится в SQLite. Подделать состояние через DevTools нельзя.

Чего это не закрывает: скрипт, честно шлющий запросы на максимальной разрешённой частоте, и скриншот чужого экрана. Против первого работает экономика — час на пределе даёт 28% при потолке 30%. Против второго — официант за столом.
